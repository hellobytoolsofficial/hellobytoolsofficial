## Popular with developers

- [JSON Formatter](https://hellobytools.com/tools/json-formatter/): format, validate and minify JSON, with the exact line and column of any error
- [Regex Tester](https://hellobytools.com/tools/regex-tester/): test a pattern against sample text with live match highlighting
- [JWT Encoder/Decoder](https://hellobytools.com/tools/jwt-encoder-decoder/): inspect a token's header and payload, sign and verify HS256/384/512
- [Base64 Encoder/Decoder](https://hellobytools.com/tools/base64-encoder-decoder/): UTF-8 safe, with URL-safe output
- [API Tester](https://hellobytools.com/tools/api-tester/): send HTTP requests and inspect the response without CORS getting in the way
- [Hash Generator](https://hellobytools.com/tools/hash-generator/): MD5, SHA-1 and SHA-256
- [UUID Generator](https://hellobytools.com/tools/uuid-generator/): v4 and v7, up to 1,000 at a time
- [HTTP Header Checker](https://hellobytools.com/tools/http-header-checker/): response headers plus a graded security-header report

## How it works

Most tools run entirely in your browser, so the text and files you work on stay on your device. A few need a server (the AI generators, the link, redirect and header checkers, live currency rates), and each of those says so on its page.
